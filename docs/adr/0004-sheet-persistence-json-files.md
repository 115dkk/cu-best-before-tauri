# ADR-0004: 조사표는 앱 데이터 폴더의 JSON 파일 하나씩, 30일 후 정리

- 상태: 채택 (2026-08-30)

## 결정

- `SheetStore`는 디렉터리 하나를 받아 `sheets/<id>.json`을 읽고 쓴다. 쓰기는 임시 파일 + rename으로 원자적이다.
- `id`는 `created_at`을 `YYYYMMDD-HHMMSS`로 포맷한 문자열. 파일명으로 안전하고 정렬이 시간순과 일치한다.
- 앱 시작(shell `setup`)에서 `purge_older_than(now, 30일)`를 호출해 `updated_at` 기준 오래된 파일을 지운다.
- 편집 화면은 변경마다 `save_sheet`를 호출한다(자동 저장). 별도 "저장" 버튼은 없다.

## 이유

- 장기 보존 계획이 없고 데이터가 수 KB라 DB가 과하다. 파일 하나 = 조사표 하나는 디버깅과 백업이 쉽다.
- 자동 저장이면 "나가거나 새 조사표를 시작하면 저장된다"는 요구를 화면 이탈 이벤트에 의존하지 않고 만족한다(Android에서 앱 종료 훅은 신뢰할 수 없다).

## 결과

- 저장 형식이 바뀌면 `Sheet`의 serde 정의가 스키마다. 하위 호환은 30일 창 안에서만 신경 쓰면 된다.
